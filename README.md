# lakehouser-users

Users of the Monarch data lakehouse.

`metadata/users.yaml` follows the same syntax as the Gene Ontology
[go-site `metadata/users.yaml`](https://github.com/geneontology/go-site/blob/master/metadata/users.yaml):
a list of entries with `accounts` (`github`, `orcid`), `groups`, `nickname` and `uri`
(the ORCID URL, or the GitHub profile URL when no ORCID is recorded yet).

Seeded from the monarch-initiative GitHub teams `ontology-curation` and `mondo-core-contributors`.
